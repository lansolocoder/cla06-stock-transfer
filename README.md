# 多仓库存调拨与批次追溯

用于本地多仓库库存调拨与批次追溯管理的命令行项目。

需要 Python 3.12，无第三方依赖。在仓库根目录运行：

```bash
python3 -m stock_transfer --help
python3 -m stock_transfer --version
python3 -m unittest discover -s tests -v
```

无参数显示帮助，未知参数以非零状态退出。

## 库存登记

把入库商品按批次登记到指定仓库，一次提交一次落账（任一行不合法则整次全部拒绝）。
批次行格式为 `批次号,生产日期,有效期至,数量`，日期为 `YYYY-MM-DD`，数量为正整数，
`--batch` 可重复提供：

```bash
python3 -m stock_transfer register \
    --warehouse WH-A --product SKU-1001 \
    --batch LOT-2024-001,2024-03-01,2025-03-01,18 \
    --batch LOT-2024-002,2024-04-02,2025-04-02,12
```

成功后输出仓库、商品、本次总数量与批次数。

## 批次查询

查询某仓库某商品下每个批次的批次号、生产日期、有效期至与现存数量；
无数据时输出空批次列表，退出码为 0：

```bash
python3 -m stock_transfer query --warehouse WH-A --product SKU-1001
```

台账数据保存在当前工作目录的 `stock_ledger.db`（SQLite），可用 `--db` 指定其他路径。
同一仓库加同一商品范围内批次号必须唯一；新批次号会追加为独立批次行。

## 调拨单提交

把指定商品按批次从来源仓调出到目标仓，一次提交一次落账（任一分配行不合法则整单全部拒绝）。
批次分配行格式为 `批次号,调出数量`，调出数量为正整数且只表示本行数量（不接受汇总数量），
`--item` 可重复提供：

```bash
python3 -m stock_transfer transfer \
    --order TR-2024-001 --from WH-A --to WH-B --product SKU-1001 \
    --item LOT-2024-001,10 \
    --item LOT-2024-002,4
```

校验规则：

- 调拨单号、来源仓、目标仓、商品代码与批次号去首尾空白后非空，目标仓不得与来源仓相同；
- 至少提供一行批次分配，同一单内批次号不得重复；
- 批次号必须是来源仓该商品已落账批次，任一行调出数量超过该批次现存数量即整单拒绝；
- 调拨单号在全部调拨单中唯一，重复单号拒绝且不改动任何记录。

提交成功后来源仓各批次现存数量扣减对应调出数量（可扣减至 0），目标仓不立即收货，
单据状态为 `in_transit`、实收数量为 0。

## 收货确认与差异处理

对一笔在途调拨单登记各批次实收情况并完成确认，整次一次落账
（任一实收行不合法则整单全部拒绝，单据与两仓数量均保持不变）。
实收行格式为 `批次号,实收数量`，实收数量为非负整数（0 表示该批次未收到货），
`--received` 可重复提供：

```bash
python3 -m stock_transfer receive \
    --order TR-2024-001 \
    --received LOT-2024-001,10 \
    --received LOT-2024-002,3
```

确认成功后：

- 单据状态变为 `received`，实收数量为本次实收总数（允许小于调出总数，差额即为在途差异）；
- 目标仓按各批次号入账对应实收数量：实收 0 的批次不产生数量、不新建批次行；
  目标仓已有同批次号时数量累加；
- 批次生产日期与有效期沿用来源仓登记该批次时的日期；
- 各批次实收数量可经 `transfer-query` 读回；来源仓此前的扣减保持不变。

校验规则（违反任一条整单拒绝，退出码非 0，并在标准错误给出原因）：

- 调拨单号与批次号去首尾空白后非空；
- 至少提供一行实收行，同一单内批次号不得重复；
- 实收行必须逐一覆盖该单全部批次：不得遗漏，也不得出现单上不存在的批次号；
- 任一批次实收数量大于该批次调出数量、为负数或不是整数；
- 调拨单号不存在，或单据已是 `received` / `cancelled` 状态（重复确认与迟到收货同样拒绝）。

## 在途查询

按调拨单号读回单号、来源仓、目标仓、商品、各批次的批次号、调出数量与实收数量、状态、整单实收总数；
无此单时输出空结果，退出码为 0。状态只可能是 `in_transit`、`received`、`cancelled`：

```bash
python3 -m stock_transfer transfer-query --order TR-2024-001
```

所有校验失败均以非零退出码退出，并在标准错误指出具体失败原因；
单据与扣减后的数量与登记数据同库持久化，跨进程可查。

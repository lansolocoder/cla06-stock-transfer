# 多仓库存调拨与批次追溯

用于本地多仓库库存调拨与批次追溯管理的命令行项目。

需要 Python 3.12，无第三方依赖。在仓库根目录运行：

```bash
python3 -m stock_transfer --help
python3 -m stock_transfer --version
python3 -m unittest discover -s tests -v
```

无参数显示帮助，未知参数以非零状态退出。

## 库存登记

把入库商品按批次登记到指定仓库，一次提交一次落账（任一行不合法则整次全部拒绝）。
批次行格式为 `批次号,生产日期,有效期至,数量`，日期为 `YYYY-MM-DD`，数量为正整数，
`--batch` 可重复提供：

```bash
python3 -m stock_transfer register \
    --warehouse WH-A --product SKU-1001 \
    --batch LOT-2024-001,2024-03-01,2025-03-01,18 \
    --batch LOT-2024-002,2024-04-02,2025-04-02,12
```

成功后输出仓库、商品、本次总数量与批次数。

## 批次查询

查询某仓库某商品下每个批次的批次号、生产日期、有效期至与现存数量；
无数据时输出空批次列表，退出码为 0：

```bash
python3 -m stock_transfer query --warehouse WH-A --product SKU-1001
```

台账数据保存在当前工作目录的 `stock_ledger.db`（SQLite），可用 `--db` 指定其他路径。
同一仓库加同一商品范围内批次号必须唯一；新批次号会追加为独立批次行。

## 调拨单提交

把指定商品按批次从来源仓调出到目标仓，一次提交一次落账（任一分配行不合法则整单全部拒绝）。
批次分配行格式为 `批次号,调出数量`，调出数量为正整数且只表示本行数量（不接受汇总数量），
`--item` 可重复提供：

```bash
python3 -m stock_transfer transfer \
    --order TR-2024-001 --from WH-A --to WH-B --product SKU-1001 \
    --item LOT-2024-001,10 \
    --item LOT-2024-002,4
```

校验规则：

- 调拨单号、来源仓、目标仓、商品代码与批次号去首尾空白后非空，目标仓不得与来源仓相同；
- 至少提供一行批次分配，同一单内批次号不得重复；
- 批次号必须是来源仓该商品已落账批次，任一行调出数量超过该批次现存数量即整单拒绝；
- 调拨单号在全部调拨单中唯一，重复单号拒绝且不改动任何记录。

提交成功后来源仓各批次现存数量扣减对应调出数量（可扣减至 0），目标仓不立即收货，
单据状态为 `in_transit`、实收数量为 0。

## 在途查询

按调拨单号读回单号、来源仓、目标仓、商品、各批次的批次号、调出数量与实收数量、状态、实收数量；
无此单时输出空结果，退出码为 0。状态只可能是 `in_transit`、`received`、`cancelled`：

```bash
python3 -m stock_transfer transfer-query --order TR-2024-001
```

## 收货确认与差异处理

针对一笔在途调拨单登记各批次实收情况并完成确认，整次一次落账（任一实收行不合法则整单拒绝、
来源仓与目标仓数量均不变）。实收行格式为 `批次号,实收数量`，实收数量为非负整数
（0 表示该批次未收到货），`--received` 可重复提供：

```bash
python3 -m stock_transfer receive --order TR-2024-001 \
    --received LOT-2024-001,9 \
    --received LOT-2024-002,4
```

校验规则：

- 调拨单号、批次号去首尾空白后非空；至少一行实收，同一单内批次号不得重复；
- 实收行必须逐一覆盖该调拨单上的全部批次：不得遗漏，也不得出现单上不存在的批次号；
- 实收数量必须为非负整数，且任一批次实收数量不得大于该批次调出数量；
- 调拨单号不存在、单据已是 `received` 或 `cancelled` 状态均拒绝，
  重复确认与迟到的收货记录不得覆盖既有实收。

确认成功后目标仓按各批次号入账对应实收数量：实收 0 时不产生数量、不新建批次行；
目标仓已有同批次号时数量累加。新批次的生产日期与有效期沿用来源仓登记该批次时的日期。
单据状态变为 `received`，实收数量为本次实收总数（允许小于调出总数，差额即收货差异）；
来源仓此前的扣减保持不变。各批次实收数量与实收总数可由 `transfer-query` 读回。

## 调拨单取消

对一笔在途调拨单登记取消，整单一次落账。取消成功后来源仓该单各分配行批次按调出数量
全额退回（以加回来源仓对应批次现存数量的方式生效），目标仓不产生任何数量或批次行、
既有数量不变；单据状态变为 `cancelled`、实收数量保持 0，各批次调出与实收数量记录
原值不变：

```bash
python3 -m stock_transfer cancel --order TR-2024-001
```

校验规则：

- 调拨单号去首尾空白后非空；
- 调拨单号不存在、单据已是 `received` 或 `cancelled`（迟到或重复的取消）均拒绝，
  不产生任何取消记录，单据状态、实收数量、两仓所有批次数量均不变。

退回只加给该单各分配行记录的批次号本身：若该批次行仍存在则数量累加、生产日期与
有效期不变；若来源仓此后经拆分、合并已删除该批次行，则按调出时该批次登记的生产日期
与有效期重建该批次号本身，不找回拆分、合并产生的新批次号。多个进程并发取消同一在途单
时最多只有一个成功落账，每个分配行的调出数量至多退回一次。取消后仍可由
`transfer-query` 读回单据全部字段与 `cancelled` 状态。

## 批次拆分

在同一仓库同一商品范围内，把一个既有批次按数量拆成两个新批次号，整次一次落账
（任一输入不合法则整次拒绝、台账不变）。拆分行格式为 `新批次号,数量`，
`--into` 必须恰好提供两行：

```bash
python3 -m stock_transfer split \
    --warehouse WH-A --product SKU-1001 --lot LOT-2024-001 \
    --into LOT-2024-001A,10 --into LOT-2024-001B,8
```

校验规则：

- 仓库代码、商品代码、来源批次号与新批次号去首尾空白后非空，
  来源批次号与两个新批次号互不相同；
- 数量为正整数，两行数量之和必须等于来源批次现存数量，不允许留有余数；
- 来源批次号必须已落账，新批次号不得与已落账批次冲突。

拆分成功后来源批次行不再保留，两个新批次各按本行数量成为独立批次行，
生产日期与有效期至均沿用来源批次的日期，该仓库该商品下总数量守恒。

## 批次合并

在同一仓库同一商品范围内，把两个既有批次合并为一个目标批次号，整次一次落账
（任一输入不合法则整次拒绝、台账不变）。`--lot` 必须恰好提供两个来源批次号：

```bash
python3 -m stock_transfer merge \
    --warehouse WH-A --product SKU-1001 \
    --lot LOT-2024-001A --lot LOT-2024-001B --into LOT-2024-001
```

校验规则：

- 两个来源批次号与目标批次号去首尾空白后非空，两个来源批次号必须不同，
  目标批次号不得等于任一来源批次号；
- 两个来源批次必须都已落账且数量均为正整数；
- 目标批次号不得与已落账批次冲突。

合并成功后两个来源批次行不再保留，目标批次成为一行独立批次，数量为两个来源
批次数量之和，生产日期取两者中较早的日期，有效期至取两者中较晚的日期。

## 盘点调整

对同一仓库同一商品下的指定批次登记盘点实存数量，把盘盈或盘亏数量一次调入台账，
整次一次落账（任一输入不合法则整次拒绝、台账与其它记录均不变）。盘点行格式为
`批次号,盘点实存数量`，盘点实存数量为非负整数（0 表示该批次实物已全部不在）：

```bash
python3 -m stock_transfer adjust \
    --warehouse WH-A --product SKU-1001 \
    --reason 月底盘点 --count LOT-2024-001,16
```

校验规则：

- 仓库代码、商品代码、批次号去首尾空白后非空，调整原因去首尾空白后必须含非空白字符；
- 盘点实存数量必须为非负整数；
- 批次号必须是该仓库该商品下已落账批次（含现存数量为 0 的批次）。

成功后该批次现存数量改为盘点实存数量，差额为正即盘盈、为负即盘亏，
批次的生产日期与有效期不变；调整原因、调整前数量、调整后数量、差额、
仓库、商品、批次号写入一条可查询的调整记录。成功输出仓库、商品、批次号、
调整前数量、调整后数量、差额与调整原因。

## 调整记录查询

按仓库与商品读回全部盘点调整记录，每条含批次号、调整前数量、调整后数量、
差额与调整原因，按登记先后顺序输出；无记录时输出空的调整记录列表，退出码为 0：

```bash
python3 -m stock_transfer adjust-query --warehouse WH-A --product SKU-1001
```

拆分与合并均不改动任何调拨单、各批次调出数量与实收数量记录，追溯查询不受影响；
盘点调整同样不改动任何调拨单、各批次调出数量与实收数量记录，批次合并与拆分
也不改动既有调整记录。

所有校验失败均以非零退出码退出，并在标准错误指出具体失败原因；
单据与扣减后的数量与登记数据同库持久化，跨进程可查。
